# Winlator

Winlator 是一個 Android 應用程式，讓你使用 Wine 和 Box86/Box64 執行 Windows (x86_64) 應用程式。<br>
本倉庫存放 Winlator 應用程式原始碼的最新更新。<br>
更多資訊和發布版本，請造訪主倉庫：https://github.com/brunodev85/winlator

# 鳴謝與第三方應用程式

- GLIBC 補丁來自 [Termux Pacman](https://github.com/termux-pacman/glibc-packages)
- Wine（[winehq.org](https://www.winehq.org/)）
- Box86/Box64 由 [ptitseb](https://github.com/ptitSeb) 開發
- Mesa（Turnip/Zink/VirGL）（[mesa3d.org](https://www.mesa3d.org)）
- DXVK（[github.com/doitsujin/dxvk](https://github.com/doitsujin/dxvk)）
- VKD3D（[gitlab.winehq.org/wine/vkd3d](https://gitlab.winehq.org/wine/vkd3d)）
- CNC DDraw（[github.com/FunkyFr3sh/cnc-ddraw](https://github.com/FunkyFr3sh/cnc-ddraw)）

特別感謝參與這些專案的所有開發者。<br>
